# AFFIX-2026 site

Interactive Next.js report for the AFFIX-2026 study.

Project overview, methodology, citation, and research layout: see the [repository root README](../README.md).

## Run

```bash
npm install
npm run dev
```

From the monorepo root: `npm run dev`.

## Stack

Next.js App Router, Tailwind CSS v4, Motion. Study data is loaded from `src/data/` (mirrored from `benchmark/publish/` and `benchmark/scores/`).
