01 — Methodology

Scoring model

Each dimension scored 0–100. Weights sum to 1.0. Prefer primary docs, GitHub, and release notes (2025–2026). Marketing claims are separated from API reality. Estimates are marked EST.

Proprietary indices: LIE (lock-in entropy ↓), CTI (cognitive tax ↓), FMC (failure-mode coverage ↑), GED (graph expressiveness ↑), RACS (RAG→agent continuum ↑), plus RHS (rewrite hazard ↓) and PR (protocol readiness ↑). RHS estimates P(outgrow primary orchestration within 12 months of production)×100.

08 — Footnotes

EST scores & evidence rules

  1. All composite and proprietary scores are EST expert estimates calibrated against primary documentation (2025–2026), not automated benchmark harnesses. They are reproducible under the stated rubrics within typical inter-rater bands (±5–8 points on PR; see falsifiers).
  2. AFFIX = Σ (scored × weightd) with AF 0.14, CS 0.13, OB 0.11, TC 0.10, EG 0.10, RE 0.09, MF 0.08, PH 0.10, DX 0.09, FP 0.06.
  3. RHS (lower better) = clamp0100( 0.28(100−RACS) + 0.22(100−FMC) + 0.18·CTI + 0.17·max(0, DX−PH) + 0.15(100−PH) ). Interpreted as EST P(outgrow primary orchestration within 12 months)×100. Verified programmatically against the matrix.
  4. PR (higher better) = 0.30·MCP_client + 0.15·MCP_server + 0.25·A2A_or_equiv + 0.15·OpenAPI_tool_bridge + 0.15·OTel_GenAI_portable. Component scores are EST checklist audits.
  5. LIE uses a 0–100 canonical scale (lower better). Draft 0–10 cluster tables must be ×10 before comparison. Coupling is dominated by ops gravity (traces, checkpoints, cloud runtimes), not import counts.
  6. CTI for Spring AI (28) assumes Spring Boot fluency; effective CTI for a Next.js engineer is EST 45–55. Persona playbooks condition SP on JVM estate.
  7. Microsoft Semantic Kernel AFFIX understates greenfield cost due to succession toward Microsoft Agent Framework; MS (AFFIX 80.91, RHS 19.4) is the greenfield reference.
  8. Contextual frameworks (LiteLLM, Inngest AgentKit, ElizaOS) appear in methodology / playbooks but are not Tier-A AFFIX-scored in this matrix.
  9. Sources: benchmark/scores/affix_matrix.json, benchmark/findings/PROPRIETARY_FINDINGS.md, benchmark/findings/persona_playbooks.md, benchmark/METHODOLOGY.md, benchmark/deep/*.
  10. This HTML report embeds the score matrix inline. Charts require no network fetch; Google Fonts load when available and fall back to system editorial stacks offline.
